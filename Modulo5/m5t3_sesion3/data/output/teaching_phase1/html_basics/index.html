05 / Sobre el proyecto

Aprendizaje a través de datos

Esta herramienta educativa visualiza información actuarial proporcionada por el usuario. El navegador procesa el archivo localmente; no se envía a servidores. Las cifras Ultimate y ATU provienen directamente del JSON, no de un modelo estimado por esta página. El ejemplo incluido es sintético.
